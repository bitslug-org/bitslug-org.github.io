Information on Terms of Service and Bitrise API Usage Policy

BitSlug is an unofficial client for Bitrise APIs. It is not affiliated, approved, or officially connected to Bitrise Inc. or its brands.

This software is developed in compliance with Bitrise's Terms of Service and Acceptable Use Policy, offering additional macOS-specific features that do not identically replicate Bitrise's main offering.

API Documentation and Version

Bitrise APIs are thoroughly documented on the DevCenter, accessible at: https://devcenter.bitrise.io/en/api.html

The current released version is v0.1, as indicated in the official documentation.

Authentication

Each API endpoint call requires authentication using a Personal Access Token or Workspace API Token, generated from the Account Settings section of Bitrise. These tokens are mandatory for all read and write operations through the API.
